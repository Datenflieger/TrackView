# TrackView v1.0.0

Initial public release of TrackView.

## Added

- New Cactus HUD element: `Track View`
- Now-playing metadata rendering (title, artist, source app)
- Playback state indicator
- Optional progress bar
- Optional thumbnail/album art rendering
- Async media polling and snapshot-based HUD updates
- Async artwork decoding and texture cache
- HUD editor resize support
- Runtime settings for compact mode and visibility behavior

## Technical

- Kotlin-based addon implementation for Fabric/Cactus
- Media session integration via `org.endlesssource.mediainterface`
- Non-blocking render path

## Assets / Docs

- New SVG icon source and generated PNG mod icon
- Professional GitHub and Modrinth banner assets
- README for GitHub and dedicated Modrinth description markdown
- Three example in-game preview images
